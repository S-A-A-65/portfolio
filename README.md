# Professional Backend Developer Portfolio

This is a modern, responsive portfolio website built for **Ahmed Salah**, featuring a dark mode aesthetic, scroll animations, and interactive project details.

## 🚀 Quick Start
Simply double-click **`index.html`** to open the website in your browser. No server or installation is required.

## 📁 Project Structure
- **`index.html`**: The main content of the website.
- **`css/style.css`**: All visual styling, colors, and responsive design rules.
- **`js/script.js`**: Logic for the Dark Mode toggle, Mobile Menu, Modals, and Scroll Animations.
- **`test_runner.html`**: A visual testing tool to verify the website's code health.

## 🛠 Customization
To personalize the content further:
1. **Images**: Replace the placeholder icon in `<div class="photo-placeholder">` (in `index.html`) with an actual `<img>` tag pointing to your photo.
2. **Projects**: Edit the text inside the `<!-- Projects Section -->` in `index.html` to update your project details.
3. **Colors**: Open `css/style.css` and change the `--accent` variable (Line 13) to switch from Teal to any other color (e.g., Purple `#bd93f9` or Blue `#0d6efd`).

## 🌐 How to Deploy (GitHub Pages)
1. Create a new repository on [GitHub.com](https://github.com).
2. Upload these files (`index.html`, `css/`, `js/`) to the repository.
3. Go to **Settings** > **Pages**.
4. Select `main` branch as the source and click **Save**.
5. Your site will be live at `https://yourusername.github.io/repo-name`.
